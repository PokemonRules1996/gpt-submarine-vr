# Жёлтый батискаф — WebXR-прототип

Небольшой статический прототип для Meta Quest 3. Он намеренно использует оригинальную геометрию и атмосферу, а не ассеты референсной игры.

## В VR

1. Откройте опубликованную HTTPS-ссылку в Meta Quest Browser и нажмите «Войти в VR».
2. Наведите луч контроллера на ручку рычага и удерживайте триггер.
3. Правый рычаг + правый стик: ход вперёд/назад/влево/вправо.
4. Левый рычаг + левый стик: подъём/спуск и поворот.
5. Повернитесь направо, удерживайте красную ручку динамо-машины и двигайте контроллером по кругу (в этой первой версии заряд идёт, пока ручка удерживается).

## На ПК

`W/A/S/D` — ход, `R/F` — глубина, `Q/E` — поворот, `C` — зарядка.

## Публикация в GitHub Pages

1. Создайте пустой репозиторий GitHub и загрузите в него эти файлы.
2. В репозитории откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. После публикации откройте показанную GitHub ссылку в Meta Quest Browser.

Для WebXR нужен HTTPS; GitHub Pages предоставляет его для опубликованного сайта.
