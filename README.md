# Abyssal Current

Мини-игра WebXR для Meta Quest 3. Откройте `index.html` с HTTPS-хостинга, затем нажмите **Enter VR** в браузере Quest.

Управление в VR:

- наведите луч на красный навигационный рычаг и удерживайте триггер; левый стик задаёт ход вперёд/назад/влево/вправо;
- нажимайте колёса «Подъём» и «Погруж.» для регулировки балластов;
- повернитесь к динамо, удерживайте триггер на её ручке и десять раз проведите правым стиком по кругу — это вернёт 42% заряда.

Кабина и горизонт не вращаются при движении: перемещается сам подводный мир, что снижает риск укачивания.

Для проверки без гарнитуры: `WASD` — ход, `Q/E` — балласт, пробел — удержание рычага.
